Campus Life — YouCode
📌 Présentation du projet

Campus Life est un site vitrine statique et responsive conçu pour faire découvrir l'univers de YouCode aux futurs et nouveaux apprenants. Il met en valeur la vie étudiante, les campus, les clubs et les événements, tout en offrant une interface moderne, intuitive et agréable à parcourir.

Réalisé à partir d'une maquette de référence conçue sur Figma, ce projet consiste à transformer une proposition graphique en pages Web fonctionnelles, en respectant les principes de conception UI/UX, la sémantique HTML5 et les bonnes pratiques CSS3.

🎯 Objectifs du projet
Reproduire fidèlement l'identité visuelle de la maquette Figma.
Concevoir plusieurs pages Web reliées par une navigation commune.
Créer une interface responsive adaptée aux mobiles, tablettes et ordinateurs.
Structurer le contenu avec des balises HTML5 sémantiques.
Organiser et réutiliser les styles CSS pour garantir un code clair et maintenable.
Appliquer les bonnes pratiques d'accessibilité Web.
Utiliser Git et GitHub pour versionner et partager le projet.
🛠️ Technologies utilisées
HTML5 : structure et organisation sémantique des pages.
CSS3 : mise en forme, mise en page et adaptation responsive.
Flexbox : organisation et alignement des éléments.
CSS Grid : création de mises en page lorsque cela est pertinent.
Media Queries : adaptation de l'interface aux différentes tailles d'écran.
Figma : référence graphique pour la conception de l'interface.
Font Awesome : intégration des icônes.
Git & GitHub : gestion des versions et hébergement du code source.
📄 Pages du site
Accueil : présentation de l'univers Campus Life et de la vie étudiante.
Campus : découverte des campus YouCode.
Inscription : formulaire permettant aux visiteurs de manifester leur intérêt pour YouCode.

🚀 Lancer le projet

Le projet est développé uniquement avec HTML5 et CSS3. Aucune installation de dépendances n'est nécessaire.

Cloner le repository :
   git clone URL_DU_REPOSITORY

Accéder au dossier du projet :
   cd Campus-Life

Ouvrir le fichier index.html dans un navigateur Web.

Il est également possible d'ouvrir le projet dans Visual Studio Code et d'utiliser l'extension Live Server pour prévisualiser le site localement.

📱 Responsive Design

L'interface est conçue pour s'adapter aux différentes tailles d'écran :

Mobile : navigation et sections adaptées aux petits écrans.
Tablette : disposition ajustée pour améliorer le confort de lecture.
Desktop : mise en page optimisée pour les écrans plus larges.
♿ Accessibilité et bonnes pratiques

Une attention particulière est portée à la structure sémantique du HTML, à la hiérarchie des titres, aux textes alternatifs des images, à la lisibilité du contenu et à l'organisation du CSS.

Le projet vise également à garantir une navigation claire et une expérience utilisateur cohérente sur les différents appareils.
